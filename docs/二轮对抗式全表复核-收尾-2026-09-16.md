## 四、收尾三项（A23 处置 / 仓库清理 / 实机验证）

### 1. A23「教学词根缺 d5」改成数据驱动
量算结论：122 个缺 d5 的教学词根里，**119 个是结构性补不出来的** —— day/room/body/take/
happy 这类常见词根，翻遍 3,029 个可切分考试词也找不到一个含它的 cet6/toefl 词；能补的只有
sea(seaport)/tend(protend)/min(vitamine) 三个，且 seaport 不是考试词、另两个是偏词/旧拼法，
为凑警告收进来反而降低词库质量（**维持报警**）。

做法沿用既有白名单模式（residue / unmodeled-distractor）：新增
`scripts/tools/build-a23-d5-gap.mjs` 从语料算出「补不出来」的词根，写
`scripts/gates/a23-d5-structural-gap.json`；`contentRules.ts` 收 `options.rootD5StructuralGap`
后跳过这些词根的 d5 警告，**validate 打印一行明说放过了多少、依据哪个文件**，能补的照常报警。
`npm run content:all` 每次重算白名单；`tests/content.test.ts` 加一条防过期断言
（白名单里的词根若真有了 d5 词就失败）。警告 142 → **23**。

> 踩坑：难度定档是 **easy 优先**（`easy ? 1 : hard ? 5 : 3`，20 号口径）。第一版写成 hard 优先，
> 把 baseball/weekday/rainfall 这类中考词误判成 d5，白名单因此漏掉 11 个本该判为结构性的词根。

### 2.5 扩词第一批：救回 -er 施事名词（+36 词）
诊断 413 个「20 号已选、21 号被拦」的词：A18 无 root 316 / A6 变体 92 / 判定可过 5。
A6 变体里最大一组是**施事名词的静音 e**（driver=drive+r），上游变体表缺 `r`，整批被 A6 拦下。
补 `r` 后 36 个常用词入表（computer/driver/eraser/manager/officer/ruler/writer/trader…）：

| 类别 | 处理 |
|---|---|
| 29 个真变体 | `er` 变体表补 `r`，照 9.3 契约写释义与例句 |
| 7 个不可拆整词 | river/liver/hover/rather/slippery/peer/taper 按 delivery 的做法整词立 root（原切分是 rive/rathe/hove/cate/pee 碎片，带出「岸」「猫」「英便士」这类垃圾义项） |
| later | 改挂新立的比较级后缀 `comper`（比较级 -er 与施事 -er 同形不同义） |
| miner | 词干从 `min`(小) 改挂新注入的 `mine`(矿) —— min 还服务 minute/minimum，不能改成「矿」 |
| 词素义连带修正 | weave 编法→编织、village 村庄乡村的→村庄、manufacture 产品→制造；产品 |

**踩坑两条**：① 干扰项生成器的「判定正则」与「生成正则」写成两份，生成侧漏了叠字过滤，
于是修出来的选项里还有「心智的的过程」—— 合成同一条 `BAD_TEXT_RE`。
② 模板按固定顺序取第一个会清一色变成「一种X的习俗」，改成按种子轮转。

### 2.6 扩词第二批：-ate 组与合法变体（+42 词，2742→2784）
| 组 | 内容 | 处理 |
|---|---|---|
| **-ate 组 22 词** | accumulate/appreciate/candidate/concentrate/considerate/fortunate/anticipate/motivate/originate/aggravate/assassinate/assimilate/formulate/insulate/illuminate/irritate/modulate/permeate/subordinate/tabulate/precipitate/certificate | 动词后缀 -ate 原先被并进了**介词 at(向、至)**，字面义成了「向……」—— 重挂 `ate` |

| **重切/整词 4 词** | independence(in+de+pend+ence)、divide(di+vid[vide])、automation(automat+ion)、heroine/routine/preface 整词 | — |

**顺手清掉 10 个垃圾义项**：simil 明喻→相似、insula 医岛→岛、lumin 腔→光、rit 计信息传输速率→刺激、

**三条踩坑**：
1. `-ine` 立不住独立 id —— id 归一化会剥掉词尾 e（ine→in）又并回前缀 in，改整词。
