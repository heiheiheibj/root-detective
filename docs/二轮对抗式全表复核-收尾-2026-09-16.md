## 四、收尾三项（A23 处置 / 仓库清理 / 实机验证）

### 1. A23「教学词根缺 d5」改成数据驱动
量算结论：122 个缺 d5 的教学词根里，**119 个是结构性补不出来的** —— day/room/body/take/
happy 这类常见词根，翻遍 3,029 个可切分考试词也找不到一个含它的 cet6/toefl 词；能补的只有
sea(seaport)/tend(protend)/min(vitamine) 三个，且 seaport 不是考试词、另两个是偏词/旧拼法，
为凑警告收进来反而降低词库质量（**维持报警**）。

做法沿用既有白名单模式（residue / unmodeled-distractor）：新增
`scripts/tools/build-a23-d5-gap.mjs` 从语料算出「补不出来」的词根，写
`scripts/gates/a23-d5-structural-gap.json`；`contentRules.ts` 收 `options.rootD5StructuralGap`
后跳过这些词根的 d5 警告，**validate 打印一行明说放过了多少、依据哪个文件**，能补的照常报警。
`npm run content:all` 每次重算白名单；`tests/content.test.ts` 加一条防过期断言
（白名单里的词根若真有了 d5 词就失败）。警告 142 → **23**。

> 踩坑：难度定档是 **easy 优先**（`easy ? 1 : hard ? 5 : 3`，20 号口径）。第一版写成 hard 优先，
> 把 baseball/weekday/rainfall 这类中考词误判成 d5，白名单因此漏掉 11 个本该判为结构性的词根。
