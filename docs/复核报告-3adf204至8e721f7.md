## 二、建议修改

### 2.1 同类垃圾义项至少还有 8 条漏网，A20b 一条都抓不到（最高优先级）

扫描全表（命中 `/单位|/药|/器|/率|/缩写|/组织|/接口/`）结果：

| 词素 | 现义项 | 应改 | 家族词 |
|---|---|---|---|
| `wf` | 滤水器 | 女人 / 女性（allomorphs 是 `wo`，用于 `woman`） | woman |
| `wer` | 文字差错率 | 人（古英语 wer；allomorphs 是 `wor`） | world 系 |
| `grav` | 格拉夫加速度单位 | 重 | gravity |
| `bute` | 保泰松一种止痛药 | 给（tribuere） | tribute |
| `statistic` | 统计量统计的 | 站立、状态 | statistical |
| `wandn` | 化暗杆内螺纹 | —（`wander` 切分整体是残渣） | wander |
| `whet` | 磨 | 存疑（疑为 whether 的误切） | — |
| `physic` | 药品 | 自然、身体（physis） | physically |

`wf` / `wer` 尤其扎眼：`woman` 现在被拆成 `wf(滤水器) + mann(人)`，玩家在拼词盘上看得见。

### 2.2 `iso = 相等` 对唯一家族词 isolate 是错的

`isolate` ← 意大利语 isola（岛），不是 iso-(相等)；且 `isolate = iso + late(携带)` 拼不出「隔离」。
建议把 isolate 移出 iso 家族（库里已有 `insula`），或把 iso 义项改成「岛、孤立」。

### 2.3 `rot = 轮转` 对 carrot 是错的

carrot ← 希腊 karōton，与 rota（轮子）无关。与 not/note 属同一类病，建议用同一套办法处理。

### 2.4 `bull = 公牛` 对 bullet 是错的

bullet ← 法语 boulette（小球）。旧值「公牛法买方」已修，但家族词仍不成立。

### 2.5 `rn = 走` 无依据

`wander = wandn[wande] + rn[r]`，表面只有一个 `r`；同词的 `wandn` 义项仍是「化暗杆内螺纹」。
这两个 id 建议整条重做或删除。

### 2.6 干扰项池混进了上述垃圾词素

本轮 ripple 后新抽出的干扰项含 `wf` / `wer` / `whet` / `hum` / `powder` / `heat` / `horizon`；
`App.tsx:294-301` 会按 id 查到并显示 `displayText + meaningCn`，
玩家在 audience 等词的拼词盘上会看到「wf / 滤水器」这类牌。

## 三、存疑待定

### 3.1 三个大家族里的既有错挂（非本轮引入，但家族变大后更显眼）

| 家族 | 错挂词 | 原因 |
|---|---|---|
| `cor`(心) 11 词 | **correct / correlate** | 这两个 `cor-` 是 com-（共同、完全），不是「心」 |
| `mit`(送、放) 10 词 | **missing** | 古英语 missan（错过、失踪），不是 mittere |
| `jud`(判断、法律) 8 词 | **adjust** | 拉丁 juxta（靠近），不是 jud- |

这 6 个词的 parts 都不在本轮改的 20 词里（git 对比确认），属既有问题；
`missing` 在旧库里就已挂在义项为「送」的 `miss` 下。

### 3.2 `sid = 坐` 配 consider，证据弱

consider 词源是 sidus（观星），教学上常归 sid=坐。旧值「计安全性标识」肯定是垃圾，
新值不算错，但家族词只有 consider 一个，无法自证。

### 3.3 `der = 剩下`（remainder = remain + der）是给残渣编的义项

无词源依据，只是比旧值「医变性反应」好。

### 3.4 三处数字对不上

- 说「85 处覆盖」，产物里**实际生效 74 条**
  （`OVERRIDE_MEANINGS` 共 89 条，13 条因 id 已合并或库中无此词素而无产物记录：
  minimus / minimum / trah / dc / puls / aggress / active / passer / courage / just / iced / tard / popul）。
- `docs/Stage3-进度交接.md:19` 写「例句覆盖 2698/2698 全部有中文对照」，
  **实测 811 词 exampleCn 为空**（A1 警告的 811 条就是它）。
- 同文档写 1035 警告「主要为 A23」，**实测 A23 仅 128 条，A1 才是 811 条**。

### 3.5 实际波及面比「只有 20 个词」大得多

parts 确实只有 20 词变，但 **distractors 变了 2682 词（99.4%）、metaphorOptions 363 词、
familyWordIds 34 词**。原因是干扰项/选项从词素义项池确定性重抽，74 条义项变化导致全库重抽。
功能上无害（A15 等闸门通过、重跑逐字节一致），但「只动了 20 个词」只在 parts 层面成立。

### 3.6 A20b / A24b 的评估（攻击点 5）

- 两条**当前命中均为 0** —— 修完之后没有任何正例可验证它们有效；
  而 2.1 的 8 条漏网**全部不匹配** `DICT_ARTIFACT_RE`，当面证明覆盖面不够。
- **不建议升 error**：`chemist / chemistry / chemic`（化学）、`poison`（毒药）、
  `organize`（组织）、`ium`（元素）都是真义项，升 error 必误伤。
- 建议保持 warning，但扩一层正则（`/单位$|/率$|/器$|/缩写|/组织|/接口/`）先跑一遍看误报率；
  更有效的办法是**导出「全部 2144 词素 id + 义项 + 家族词」清单交给第二个 AI 全表过一遍** ——
  这次的病本质上是靠「全表人工扫」发现的，正则永远只能兜一角。
- 盲区：A20b / A24b 写在 `scripts/validate-content.mjs:58-87`，不在 `contentRules.ts`，
  所以 `tests/content.test.ts` 的「规则闸门零错误」**根本跑不到它们**，`npm test` 对这两条完全无感。
